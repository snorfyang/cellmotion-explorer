Background

Why these tracks matter

MCF10A live imaging provides the biological context for CellMotion Explorer. The visual reference helps explain what is being observed before the analysis turns to trajectories, record boundaries, and evidence.

From microscopy to track data

The external microscopy image is a representative context reference. The model input remains the project tracking files, which preserve cell identifiers, frame continuity, and time settings. Keeping those layers separate makes the later SciencePal audit easier to inspect.

What to look for

Observed movement

Cells change position over time, creating trajectories that can be compared across records.

Evidence boundary

A visual pattern can motivate a question, but it does not by itself prove a mechanism or predictive gain.
